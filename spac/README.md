# 스팩 균등청약 알림 시스템

> 블로그 작업과는 별개인 개인 투자 도구다. 투자 권유가 아니며 최종 판단은 본인이 한다.

## 목표
스팩을 **균등배정으로만** 청약하고 **상장 첫날 매도**한다. 이때 청약수수료를 넘는 수익이 날 종목만 골라 Gmail로 알림을 받는다.

## 구조
```
매일 07:47 (평일)  Claude 루틴 실행  →  ROUTINE.md 절차대로
  ① 청약 예정 스팩 수집      data/candidates.json
  ② 최근 상장 스팩 성과 기록  data/history.csv
  ③ python3 calc.py        예상 배정주·손익분기·등급 계산
  ④ Gmail 발송             소식 있을 때만 (월요일은 주간 요약)
```

| 파일 | 역할 |
|---|---|
| `settings.json` | 청약수수료, 거래세, 등급 기준 (직접 수정 가능) |
| `calc.py` | 계산기. `python3 calc.py --today 2026-09-08`처럼 과거 날짜로 재현 가능 |
| `data/history.csv` | 최근 스팩 상장 첫날 성과 (시장 분위기 판단용) |
| `data/my_trades.csv` | 내 실제 청약·매도 기록 (복기용, 직접 입력) |
| `ROUTINE.md` | 매일 자동 실행 절차 |
| `data/intraday.csv`, `timing.py` | 상장 첫날 시각별 가격 → 시간대별 상승률 표 |
| `listed.py`, `data/listed.csv`, `data/holdings.csv` | 기존 상장 스팩 저가매수(≤1,950원) → +10% 매도 신호 |
| `reports/` | 분석 보고서 (2026 증권사별 성과·잔여 수익 전망) |

## 계산 방식
- **균등 물량** = 일반청약 물량 × 50%
- **1인 배정주** = 균등 물량 ÷ 청약건수 (1주 미만이면 추첨)
- **순이익** = 배정주 × (매도가 − 2,000) − 청약수수료 − 매도금액 × (거래세 0.20% + 매매수수료)
- **등급**
  - 기준 상승률: 최근 스팩 **시초가 평균**. 시초가 데이터가 없으면 **기사 속 장 초반 가격 평균의 절반**(보수 가정)
  - 기준 배정주: 청약건수를 모르면 **최근 스팩의 실제 균등배정 주식수**(현재 약 5주)
  - **A (청약 추천)**: 기준 상승률로 팔았을 때 기대이익이 3,000원 이상이고, 수요예측이 1,000:1 이상
  - **B (선택)**: 기대이익이 0원보다 크다
  - **C (비추천)**: 그 밖의 경우
  - **?**: 데이터가 부족해 계산하지 못함

## 한국제17호 재현 결과 (2026-09-08 기준으로 계산)
- 조건: 일반청약 175만 주(균등 87.5만 주), 수요예측 1,270.51:1, 수수료 2,000원 가정
- 청약 10만 건이면 1인 8주 → 손익분기 **+12.7%**
- 청약 40만 건이면 1인 2주 → 손익분기 **+50.3%**
- 실제 첫날 흐름: 장중 최고 5,220원(+161%), 종가 2,170원(+8.5%)
  ([아주경제](https://www.ajunews.com/view/20260922091800089), [데이터투자](https://www.datatooza.com/article/20260909150542518352ef3c061b_80))
- 교훈: **언제 파느냐가 수익을 좌우한다.** 배정이 적으면 종가에 팔았을 때 수수료도 못 건질 수 있다.
