# [중학 과학 × AI] 티처블 머신으로 '생물 분류' 수업하기 — 학생이 직접 AI를 가르쳐보는 45분

## 이 도구, 이럴 때 쓰세요

과학에서 **분류**는 "기준을 정하고, 그 기준에 따라 나누는 것"입니다. 그런데 학생들은 분류를 '외우는 것'으로 받아들이기 쉽죠.

티처블 머신은 사진 몇십 장만 보여주면 AI가 스스로 기준을 찾아 분류하도록 **학습**시키는 도구입니다. 학생이 AI에게 분류를 가르치다 보면, 자연스럽게 이런 질문이 나옵니다.

- "AI는 **무엇을 보고** 구분한 걸까?"
- "왜 **틀렸을까?** 데이터가 부족했나?"
- "사람이 쓰는 분류 기준과 AI의 기준은 같을까?"

바로 이 질문들이 수업의 핵심입니다.

## 시작 전 체크

| 항목 | 내용 |
|---|---|
| 가격 | 무료 |
| 학생 로그인 | 학습·테스트는 불필요 (모델 저장/공유 시 구글 계정) |
| 기기 | 웹캠 있는 PC·크롬북·태블릿 (크롬 권장) |
| 준비물 | 분류할 실물 또는 사진 (나뭇잎, 곤충 사진 카드 등) |
| 개인정보 | 웹캠 사용 시 학생 얼굴이 화면에 잡히지 않게 **사물만** 비추기 |

## 단계별 사용법

### STEP 1. 이미지 프로젝트 만들기
teachablemachine.withgoogle.com 접속 → **시작하기** → **이미지 프로젝트** → **표준 이미지 모델**

🖼️ [캡처 1: 프로젝트 선택 화면]

### STEP 2. 클래스(분류 기준) 만들기
'Class 1', 'Class 2' 이름을 바꿔 분류 그룹을 정합니다.
예) `잎맥이 나란한 잎` / `잎맥이 그물 모양인 잎`

🖼️ [캡처 2: 클래스 이름 입력]

### STEP 3. 데이터 넣고 학습시키기
각 클래스마다 **웹캠**으로 찍거나 사진을 **업로드** → **모델 학습시키기** 클릭

> 💡 팁: 클래스별 사진 수를 비슷하게 맞추세요. 한쪽이 훨씬 많으면 AI가 그쪽으로 치우칩니다. → 이것 자체가 좋은 토론 거리!

🖼️ [캡처 3: 샘플 추가 & 학습 버튼]

### STEP 4. 테스트하고 틀린 이유 찾기
미리보기 창에 **학습에 안 쓴 새 잎**을 보여주고 결과(%)를 확인합니다.

🖼️ [캡처 4: 미리보기 결과 막대]

## 수업 흐름 (45분)

| 단계 | 시간 | 활동 |
|---|---|---|
| 도입 | 5' | "여러분은 이 잎 두 장을 어떻게 구분했나요?" — 사람의 분류 기준 떠올리기 |
| 전개1 | 10' | 모둠별 분류 기준 정하기 → 클래스 이름 짓기 |
| 전개2 | 15' | 데이터 모으고 학습시키기 (모둠당 기기 1대) |
| 전개3 | 10' | 다른 모둠의 잎으로 테스트 → **AI가 틀린 사례** 기록 |
| 정리 | 5' | "AI가 틀린 이유 = 데이터·기준의 문제" 정리, 과학의 분류와 연결 |

🟡 **[실제 수업 사진 자리]** — 모둠 활동 손 클로즈업, 활동지 (이름 가림)

## 수업에서 쓰기 좋은 질문

1. AI는 잎의 **모양, 색, 배경** 중 무엇을 보고 판단했을까?
2. 배경을 바꾸면 결과가 달라질까? (→ 실제로 해보기)
3. 과학자들이 정한 분류 기준과 AI가 찾은 기준의 차이는?
4. 데이터를 **어떻게** 모아야 더 공정한 AI가 될까?
