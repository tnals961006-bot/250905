# 티처블 머신 과학 수업 | 중1 생물 분류를 AI에게 가르쳐본 기록

📷 [대표사진: 썸네일 — AI 생성 이미지]

[인용구]
**이 기록의 요약**
· 대상: 중학교 1학년 과학, 45분 1차시
· 도구: 티처블 머신(Google) — 무료, 로그인 없이 사용 가능
· 핵심: 학생이 AI에게 '분류'를 가르치면서, 분류 기준이 왜 중요한지 스스로 발견하게 하는 수업

[구분선]

■ 분류를 '외우는 것'으로 여기는 아이들

생물 분류 단원을 가르칠 때마다 비슷한 장면을 만난다. 학생들은 분류 결과는 곧잘 외우지만, **왜 그렇게 나누는지**는 잘 묻지 않는다. 분류는 기준을 세우고 그 기준에 따라 나누는 일이다. 결과보다 기준이 핵심이다.

🟡 (이 수업을 떠올리게 된 계기 1~2문장 — 예: 작년 수업에서 있었던 일, 학생 질문 등)

그래서 이번에는 순서를 바꿔 보기로 했다. 학생이 분류를 배우는 대신, **학생이 AI에게 분류를 가르치게** 하는 것이다.

📷 [사진: 수업 도입 판서 또는 수업 준비물 — 구글 드라이브 업로드 예정]

■ 티처블 머신은 어떤 도구인가

티처블 머신은 구글이 만든 무료 웹 도구다. 사진 몇십 장을 보여주면 AI가 그 안에서 스스로 특징을 찾아 분류하는 법을 **학습**한다. 코딩이 필요 없고, 학습과 테스트까지는 로그인도 필요 없다.

[표]
| 항목 | 내용 |
|---|---|
| 비용 | 무료 |
| 로그인 | 학습·테스트는 불필요 (모델 저장·공유 시 구글 계정) |
| 기기 | 카메라 있는 노트북·크롬북·태블릿, 크롬 브라우저 권장 |
| 준비물 | 분류할 실물 잎 또는 사진 카드 |

과학 수업에서 이 도구가 좋은 이유는 하나다. AI가 **틀린다**. 그리고 틀린 이유를 따라가다 보면 결국 '데이터'와 '기준' 이야기로 돌아온다. 과학의 분류가 다루는 바로 그 지점이다.

[구분선]

■ 사용 방법 4단계

**STEP 1. 이미지 프로젝트 만들기**
teachablemachine.withgoogle.com 접속 → 시작하기 → 이미지 프로젝트 → 표준 이미지 모델

📷 [캡처 1: 프로젝트 선택 화면]

**STEP 2. 분류 그룹(클래스) 이름 정하기**
'Class 1', 'Class 2'의 이름을 모둠이 정한 분류 기준으로 바꾼다.
예) 나란히맥 잎 / 그물맥 잎

📷 [캡처 2: 클래스 이름 입력 화면]

**STEP 3. 데이터 넣고 학습시키기**
클래스마다 카메라로 찍거나 사진을 올린 뒤 '모델 학습시키기'를 누른다. 클래스별 사진 수는 비슷하게 맞춘다. 한쪽이 많으면 AI가 그쪽으로 기운다. 이 차이 자체가 수업에서 좋은 토론 거리가 된다.

📷 [캡처 3: 샘플 추가 및 학습 버튼]

**STEP 4. 새 잎으로 테스트하기**
학습에 쓰지 않은 잎을 카메라에 비추고 결과(%)를 확인한다. 틀린 경우를 기록해 두는 것이 이 수업의 핵심이다.

📷 [캡처 4: 미리보기 결과 막대]

[구분선]

■ 수업 흐름 (45분)

[표]
| 단계 | 시간 | 활동 |
|---|---|---|
| 도입 | 5분 | 잎 두 장 제시 — "어떻게 구분했나?" 사람의 분류 기준 떠올리기 |
| 전개 1 | 10분 | 모둠별 분류 기준 정하기, 클래스 이름 짓기 |
| 전개 2 | 15분 | 데이터 모으기 → AI 학습 (모둠당 기기 1대) |
| 전개 3 | 10분 | 다른 모둠의 잎으로 테스트, AI가 틀린 사례 기록 |
| 정리 | 5분 | "AI가 틀린 이유 = 데이터와 기준의 문제" → 과학의 분류와 연결 |

■ 수업 중에 던진 질문

1. AI는 잎의 모양, 색, 배경 중 무엇을 보고 판단했을까?
2. 배경을 바꾸면 결과가 달라질까? (실제로 바꿔서 확인)
3. 과학자가 정한 분류 기준과 AI가 찾은 기준은 같을까?
4. 더 믿을 만한 AI를 만들려면 데이터를 어떻게 모아야 할까?
