# 네이버 블로그 운영 가이드

## 블로그 기본 설정 (확정)
| 항목 | 값 |
|---|---|
| 플랫폼 | 네이버 블로그 (스마트에디터 ONE) |
| 글쓴이 | 현직 중학교 과학 교사, 1·3학년 담당 |
| 독자 | 교육에 관심 있는 모든 사람 (교사·학부모·학생·일반) |
| 문체 | **기록체** (~했다, ~이다). 독자에게 말 거는 문장은 최소화 |
| 사진 | 구글 드라이브 → Claude가 가져와 배치 |

## 기록체 원칙
- 종결: `~했다 / ~이다 / ~였다 / ~것 같다`
- 교사 용어는 한 번 풀어쓴다: "성취기준(교육과정에서 정한 학습 목표)"
- 독자 폭이 넓으므로: 첫 문단은 **누구나 이해할 상황**, 수업 디테일은 뒤쪽 표로
- 마무리 CTA도 기록체: "다음 기록에서는 ○○를 해볼 예정이다."

## 제목 공식 (네이버 검색 노출)
`핵심키워드를 앞쪽에` + `대상` + `구체 결과`, 25~35자
- ✅ 티처블 머신 과학 수업 | 중1 생물 분류를 AI로 가르친 기록
- ❌ 오늘 수업 이야기

## 스마트에디터 변환 규칙 (초안 표기 → 에디터 요소)
| 초안 표기 | 에디터에서 |
|---|---|
| `[인용구]` | 인용구(따옴표 또는 버티컬 라인 스타일) |
| `[구분선]` | 구분선 |
| `📷 [사진: …]` | 사진 삽입 + 사진 아래 설명(캡션) |
| `[표]` | 표 삽입 |
| `**굵게**` | 굵게 + 필요 시 배경색 강조 |
| 소제목 `■` | 본문 '소제목' 스타일 |

## 분량·구성
- 본문 1,500~3,000자, 사진 8~15장 (문단 2~3개마다 1장)
- 문단은 2~4줄. 모바일에서 한 화면에 사진 or 문단 하나
- 대표사진(썸네일)은 **정사각형** 우선 — 목록·검색에서 정사각으로 잘린다

## 태그
- 10개 내외: 큰 키워드 3 (중학교과학, AI교육, 서울교육) + 세부 키워드 5~7
- 시리즈 태그 고정: `#과학쌤기록`

## 발행 전 체크
- [ ] 제목 앞부분에 검색 키워드
- [ ] 대표사진 지정
- [ ] 학생 얼굴·이름·학교명·위치 노출 없음
- [ ] AI 이미지 캡션 표기
- [ ] 카테고리 지정 (중학과학 / AI교육 / 서울교육 / 교단기록)
